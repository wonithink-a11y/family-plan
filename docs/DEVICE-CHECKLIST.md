# 실기기 점검표 (갤럭시 탭 S8+ 가로 · 폰)

클라우드 환경에서는 가짜 서버로만 시험했습니다. 아래는 **태블릿·폰에서 직접 봐야만 알 수 있는 것**입니다. 앱 버전은 우리집 머리 오른쪽 작은 글자(`v4.xx`)에서 확인합니다. 먼저 앱을 완전히 닫았다가 다시 열어 최신 버전인지 봅니다(`CACHE_NAME`이 올라가야 설치된 앱이 갱신됩니다).

**알려 주실 때**: 번호 + 결과(됨 / 안 됨 / 이상함) 한 줄이면 됩니다. 이상하면 화면 캡처를 같이 보내 주세요. 소리가 안 나거나 오류 문구가 뜨면 그 문구를 그대로 적어 주세요.

## A. 먼저 (5분) — 화면이 제대로 나오는지
| # | 확인 | 기대 | 결과 |
|---|---|---|---|
| A1 | 태블릿 가로로 우리집 탭 열기 | 기본은 **딸 기준** 한 화면(날씨·루미·아침 루틴·도장·수행평가·준비물), 스크롤 없음. 머리 오른쪽에 [딸·아빠·엄마·전체] 선택 칩 | ☐ |
| A2 | 화면 아래가 잘리지 않는지 (딸 칸의 "도장 찍기" 줄, 오른쪽 준비물 줄) | 끝까지 보임. 주소창이 보이는 상태에서도 확인 | ☐ |
| A3 | 선택 칩에서 아빠 / 엄마 / 전체 눌러 보기 | 아빠·엄마: 그 사람 일정만 넓게(＋로 그 사람 일정 등록). 전체: 아빠·엄마·딸 3칸이 한 화면에 들어옴(항목이 많을 때 칸 안 스크롤). 다시 딸을 누르면 원래대로. 앱을 닫았다 열어도 마지막 선택이 유지됨 | ☐ |
| A4 | 머리 오른쪽 첫 아이콘(◐ / 해 / 달) 누르기 | 누를 때마다 자동 → 라이트 → 다크 → 자동. 소리는 안 남 | ☐ |
| A5 | 왼쪽 세로 메뉴(우리집·일정·수행평가·가이드·설정) | 글자·아이콘이 잘리지 않고 눌림이 자연스러움 | ☐ |
| A6 | 라이트 / 다크 둘 다에서 우리집·설정·가이드 | 흰 카드 잔상, 글자 안 보임, 아이콘이 묻히는 곳 없음 | ☐ |
| A7 | 폰 세로로 우리집 | 1열 스크롤 배치. 하단 메뉴 | ☐ |

## B. 입력·알림이 손에 맞는지
| # | 확인 | 기대 | 결과 |
|---|---|---|---|
| B1 | 칭찬 "도장 찍기" → PIN 키패드 | 큰 숫자판이 나오고 OS 키보드는 안 뜸. 틀리면 흔들리고, 5번 틀리면 30초 잠김 | ☐ |

| B3 | 일정 등록 / 준비물 요청 폼 | 위와 같음. 시트가 화면 밖으로 나가지 않음 | ☐ |
| B4 | 아침 루틴 항목 편집(연필 아이콘) | 목록에서 글자 수정, 위·아래 이동, 추가·삭제. 키보드가 떠도 목록이 스크롤됨. 저장하면 오늘 체크가 남아 있음 | ☐ |
| B5 | 일정 삭제(반복 일정이면 "이 날짜만/전체/취소"), 수행평가 삭제 | 확인 시트가 뜨고 기본 포커스는 "취소". 빨간 삭제 버튼 | ☐ |
| B6 | 설정 → 데이터 관리 → 전체 초기화 | **먼저 부모 PIN**, 그다음 위험 확인. (실제로 지우지는 말고 취소) | ☐ |
| B7 | 저장·복사 같은 동작 뒤 안내 토스트 | 폰은 하단 메뉴 위, 태블릿은 아래 가운데. 가려지지 않음 | ☐ |
| B8 | 루미 시트를 연 채 알림이 뜨면(예: 목소리 미리 듣기) | 알림이 시트 위쪽에 뜸 | ☐ |
| B9 | 루틴을 전부 체크 / 도장 찍기 | 화면 가운데에 큰 "도장 +1" 안내. 10개가 되면 구입권 | ☐ |
| B10 | 도장이 10개가 될 때 | 큰 안내에 "구입권이 생겼어요 / 종류를 골라 보세요". 우리집에 "구입권 1장 · 고르기" | ☐ |
| B11 | 구입권 화면 → [종류 고르기] | 책·영화·외식 중 하나를 고르면 이름이 바뀌고 [사용하기]가 생김. 고르기 전에는 사용 불가 | ☐ |
| B12 | 설정 → 구입권 종류 편집(부모 PIN) | 목록에서 이름을 고치고 추가·삭제·순서 바꾸기. 다음에 받는 구입권부터 반영, 이미 받은 것은 그대로 | ☐ |

## F. 아직 만들지 않은 것 (점검 대상 아님)
- 화면이 꺼진 상태의 호출어, 앱이 닫혀 있을 때의 푸시 알림은 웹앱으로 불가능합니다(푸시 서버는 미배포, Blaze 요금제 필요).
- 자녀별 프로필(도장·루틴 분리)은 결정 대기입니다. 도장을 써서 상품을 교환하는 방식의 상점도 만들지 않았습니다(구입권 종류 고르기까지만).

## 결과 정리법
1. 체크한 표를 그대로 보내거나, "A2 잘림 / C3 에코" 처럼 문제 번호만 적어도 됩니다.
2. 문제가 있으면 고치는 순서: 데이터 손실·저장 실패 → 화면 잘림·가려짐 → 소리·마이크 → 모양.
3. 전부 통과하면 `HANDOVER.md`의 "아직 검증되지 않은 것"을 지우고 "실기기 확인 완료(날짜)"로 바꿉니다.
